# Cocoon Profile Rationale

This document explains why each built-in profile exists and when it may or may not fit a user.

## Important note

These profiles are starting presets, not diagnoses or treatment plans. People with the same diagnosis can need different settings.

## ADHD profile

Current preset:

- Dark mode: off
- Reduced motion: on
- Hide algorithmic feeds: on
- Grounding tool: on

Why it can help:

- Reducing motion can lower visual distraction.
- Hiding algorithmic feeds can reduce impulsive scrolling loops.
- Grounding tool gives a quick interruption point when attention drifts.

When to adjust:

- Turn dark mode on if bright pages cause strain.
- Disable global feed hiding if user needs specific platform feeds for work.

## Autism profile

Current preset:

- Dark mode: on
- Reduced motion: on
- Hide algorithmic feeds: on
- Grounding tool: on

Why it can help:

- Reduced motion can reduce sensory overload from animations.
- Dark mode can reduce brightness sensitivity.
- Feed hiding can reduce unpredictable, high-intensity content.

When to adjust:

- Some users prefer light mode with stronger contrast instead of dark mode.
- For users who rely on community feeds, use per-site overrides instead of global hide.

## Anxiety profile

Current preset:

- Dark mode: on
- Reduced motion: on
- Hide algorithmic feeds: off
- Grounding tool: on

Why it can help:

- Reduced motion + dark mode can reduce physiological arousal triggers from visual intensity.
- Grounding tool provides immediate regulation support.
- Leaving feed hiding off by default avoids aggressive avoidance patterns for users who still need access.

When to adjust:

- If doomscrolling patterns are present, enable feed hiding globally or per-site.
- If dark mode increases discomfort, switch it off while keeping reduced motion on.

## Custom profile

Use custom when:

- User has mixed needs (e.g., ADHD + autism traits).
- Work/school requirements differ by site.
- User needs controlled experimentation without changing presets.

## Why this mapping makes sense for neurodivergent users

- It prioritizes sensory load reduction (dark mode, reduced motion).
- It supports attention protection (feed cleaner + per-site overrides).
- It includes immediate self-regulation support (grounding overlay).
- It keeps user autonomy central via granular toggles and per-site controls.

## Known limitations

- Adaptive profile suggestions (domain rules + time schedules) are opt-in and suggestions-only today; Cocoon does not auto-switch profiles without an explicit user action.
- No dedicated dyslexia reading preset yet.
- No language/tone interpretation helper yet (e.g., sarcasm support).

These are candidates for future profile expansion.
