Support

How to install Cocoon, report issues, and what to include.

Install Cocoon

Cocoon is not on the Chrome Web Store yet, so it installs from source. It takes about a minute and needs Node and Chrome.

  1. Clone github.com/gr8monk3ys/cocoon.
  2. Run npm install && npm run build to produce dist/.
  3. Open chrome://extensions and turn on Developer mode.
  4. Choose Load unpacked and pick the dist/ folder.

Nothing is sent anywhere during install or after it. When the Web Store listing goes live this page will link to it instead.

Report an Issue

When filing a bug, include:

  1. Cocoon version (from manifest.json in the extension)
  2. Browser version
  3. Affected website domain
  4. Which toggles were enabled
  5. Steps to reproduce
  6. Expected vs actual behavior

Known Limitations

  • Social platform DOM changes may break feed selectors until rules are updated.
  • Per-site overrides apply only to supported social domains.
  • Grounding overlay is intentionally lightweight and not a clinical intervention.

Safety Note

Cocoon is a supportive accessibility and wellbeing tool and is not a substitute for professional medical or mental health care.

If you are in immediate danger or crisis, contact local emergency services or your regional crisis line.
