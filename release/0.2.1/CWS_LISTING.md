## Detailed description

Cocoon is a privacy-first Chrome extension designed to reduce online overwhelm for neurodivergent and mental health-affected users.

Features:

- Feed cleaner for supported social platforms (domain-scoped rules, no `<all_urls>`)
- Per-site overrides so you stay in control per domain
- Sensory controls (dark mode + reduced motion)
- Optional grounding overlay for quick breathing and 5-4-3-2-1 grounding
- Scenario quick-switches that auto-expire and restore your baseline settings

Privacy:

- No accounts
- No analytics
- No third-party trackers
- Settings stored locally in `chrome.storage.local`

Safety note: Cocoon is a supportive wellbeing and accessibility tool and is not a substitute for professional medical or mental health care.

## Permission justifications (Chrome Web Store)

- `storage`: store your settings locally.
- `activeTab`: read the active tab's hostname when you open the popup so Cocoon can show and change the current-site override.
- `alarms`: auto-expire scenario quick-switches and restore your baseline settings after the timer ends.
- Host permissions (supported domains only): required to run the content script on those sites.
